# aube v3

This file tracks worthwhile breaking changes to batch into a future major
release. Items belong here when they improve the long-term API or defaults but
do not justify a major release on their own.

## Platform support

### Drop Intel macOS FFI support

Stop building the `x86_64-apple-darwin` C ABI library and publishing the
`@jdxcode/aube-ffi-darwin-x64` package. Remove it from the root FFI package's
optional dependencies and platform loader at the same time.

## Security defaults

### Enable jailed dependency builds by default

Change `jailBuilds` from `false` to `true`. Call out the opt-out and permission
settings in the migration guide for packages whose build scripts need broader
filesystem, environment, or network access.

## Rust library APIs

### Remove the three-argument `aube_lockfile::pnpm::write`

Remove `aube_lockfile::pnpm::write(path, graph, manifest)`, which takes the
lockfile's directory as the project root, and keep
`write_with_project_root(path, project_root, graph, manifest)` as the way to
write a pnpm-format lockfile. Member `link:` versions are written relative to
the member and anchored at that root, so a graph whose paths are relative to
another directory gets wrong paths from the three-argument form. In-repo
callers already pass the root explicitly; the three-argument form stays only
for API compatibility.
